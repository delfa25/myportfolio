# Portfolio — Mama Fadel DIAWARA (Angular)

Jeune ingénieur formé à l'Institut Burkinabé des Arts et Métiers (IBAM), titulaire d'une Licence en Méthodes Informatiques Appliquées à la Gestion des Entreprises (MIAGE). Passionné par la résolution de problèmes complexes à l'aide des technologies, je cherche à mettre mes connaissances en pratique dans un environnement dynamique et innovant.

## Stack & Fonctionnalités Modernes

- **Angular** (Standalone Components, Signals, Reactive State)
- **Design System SCSS** (Glassmorphism, Thème Sombre / Clair avec persistance `localStorage`)
- **Multilingue FR / EN** instantané
- **Animations au défilement** (`IntersectionObserver` via directive `[appScrollReveal]`)
- **Filtres interactifs** pour les compétences et les projets (Web, Mobile, Systèmes & Réseaux)
- **Sélecteur de messagerie intelligent** (Gmail, Outlook, Yahoo, Proton, Zoho, Client par défaut)

## Commandes de développement

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement (http://localhost:4200)
npm start

# Compiler pour la production (dossier dist/myportfolio)
npm run build
```
